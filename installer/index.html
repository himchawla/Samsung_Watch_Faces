Watch Face Installer

Install this repo's faces on your watch over Wi-Fi. Keep the watch and this computer on the same network.

Watch

Connect a watch
  1. On the watch: Settings → About watch → Software, tap Software version 5 times to enable developer options.
  2. Settings → Developer options: turn on ADB debugging and Wireless debugging.
  3. First time only: in Wireless debugging tap Pair new device and enter the pairing IP:port and code below.
  4. Then enter the IP address & port shown on the main Wireless debugging screen (it differs from the pairing port) and press Connect.
